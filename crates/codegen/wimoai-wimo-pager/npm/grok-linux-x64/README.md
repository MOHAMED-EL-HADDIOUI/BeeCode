# @wimo ai-official/wimo-linux-x64

Platform-specific binary for [`@wimo ai-official/wimo`](https://www.npmjs.com/package/@wimo ai-official/wimo) on linux-x64.

Do not install this package directly. Install the main package instead:

```sh
npm install -g @wimo ai-official/wimo
```

The main package will automatically pull the correct binary for your platform via `optionalDependencies`.
