# @beecode-official/beecode-win32-x64

Platform-specific binary for [`@beecode-official/beecode`](https://www.npmjs.com/package/@beecode-official/beecode) on win32-x64.

Do not install this package directly. Install the main package instead:

```sh
npm install -g @beecode-official/beecode
```

The main package will automatically pull the correct binary for your platform via `optionalDependencies`.
